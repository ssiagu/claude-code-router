# Story 2.2: 实现可用模型列表功能

## Status
Ready for Review

## Story

**作为** 应用用户  
**我需要** 查看所有可用的提供商和模型列表  
**这样** 就能知道我有哪些模型选择，避免输入错误的模型名称

## Acceptance Criteria

1. `ccr mode --list` 命令按提供商分组显示所有可用模型
2. 当前使用的模型在列表中高亮显示
3. 每个提供商显示其支持的所有模型
4. 列表格式易于阅读和查找，包含视觉分隔
5. 支持长模型列表的合理分页或格式化显示
6. 显示模型的基本信息（如特殊标识或功能标记）
7. 提供模型总数统计信息

## Dev Notes

### 现有系统集成信息

**配置结构** (基于现有系统):
```json
{
  "Providers": [
    {
      "name": "deepseek",
      "models": ["deepseek-chat", "deepseek-coder"]
    },
    {
      "name": "openrouter", 
      "models": ["gpt-4", "claude-3"]
    }
  ],
  "Router": {
    "default": "deepseek,deepseek-chat"
  }
}
```

**复用现有模块**:
- `src/utils/index.ts` - `readConfigFile()` 获取配置
- `src/utils/modeCommand.ts` - `getCurrentDefaultModel()` 获取当前模型
- `src/middleware/commandParser.ts` - 参考现有的模型显示格式优化

**输出格式设计**:
```
可用模型列表 (2个提供商, 4个模型):

📁 deepseek
  ✅ deepseek-chat        (当前使用)
  ⚪ deepseek-coder

📁 openrouter  
  ⚪ gpt-4
  ⚪ claude-3

使用方法: ccr mode <提供商>,<模型>
示例: ccr mode deepseek,deepseek-coder
```

**性能考虑**:
- 配置解析一次性完成
- 避免重复的文件I/O操作
- 大列表时的内存使用优化

**视觉增强**:
- 使用Unicode符号增强可读性
- 当前模型使用 ✅ 标记
- 其他模型使用 ⚪ 标记
- 提供商使用 📁 文件夹图标

**错误处理**:
- 配置文件读取失败
- 空的提供商列表
- 格式错误的配置数据

### Testing

**测试标准**:
- **测试文件位置**: `tests/utils/modelsList.spec.ts`
- **测试框架**: Jest
- **覆盖率要求**: > 90%

**核心测试场景**:
```typescript
describe('showAvailableModels', () => {
  it('should display all providers and models', async () => {
    const result = await showAvailableModels();
    expect(result.success).toBe(true);
    expect(result.message).toContain('可用模型列表');
    expect(result.message).toContain('deepseek');
    expect(result.message).toContain('deepseek-chat');
  });
  
  it('should highlight current model', async () => {
    const result = await showAvailableModels();
    expect(result.message).toContain('✅');
    expect(result.message).toContain('当前使用');
  });
  
  it('should show provider grouping', async () => {
    const result = await showAvailableModels();
    expect(result.message).toContain('📁');
  });
  
  it('should display model statistics', async () => {
    const result = await showAvailableModels();
    expect(result.message).toMatch(/\d+个提供商/);
    expect(result.message).toMatch(/\d+个模型/);
  });
});
```

**CLI集成测试**:
```typescript
describe('CLI --list option', () => {
  it('should execute ccr mode --list successfully', async () => {
    const result = await execCLI(['mode', '--list']);
    expect(result.exitCode).toBe(0);
    expect(result.stdout).toContain('可用模型列表');
  });
});
```

**边界条件测试**:
- 空提供商列表
- 单一提供商场景
- 大量模型列表性能测试
