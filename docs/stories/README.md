# ccr mode 功能用户故事总览

## 📋 项目信息

- **项目名称**: Claude Code Router ccr mode 功能
- **故事创建日期**: 2025-01-23
- **负责产品负责人**: Sarah
- **基于文档**: PRD v1.0, 架构文档 v1.0
- **开发方法**: 敏捷开发 (Scrum)

## 🎯 项目目标

为 Claude Code Router 添加 `ccr mode` 命令功能，允许用户通过命令行直接切换默认模型配置，提升工作效率并减少重复配置的工作量。
