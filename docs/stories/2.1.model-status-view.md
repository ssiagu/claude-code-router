# Story 2.1: 实现模型状态查看功能

## Status
Ready for Review

## Story

**作为** 应用用户  
**我需要** 能够查看当前的默认模型配置和系统状态  
**这样** 就能确认系统的当前设置，了解配置来源和最后修改信息

## Acceptance Criteria

1. `ccr mode` 无参数命令显示当前默认模型信息
2. `ccr mode --show` 别名功能正常工作，输出与无参数一致
3. 显示配置文件路径和最后修改时间
4. 输出格式清晰易读，包含关键状态信息
5. 正确处理配置文件不存在或损坏的情况
6. 显示信息包含提供商和模型名称的详细信息
7. 命令执行时间 < 200ms，响应迅速

**测试标准**:

**核心测试场景**:
```typescript
describe('showCurrentMode', () => {
  it('should display current model configuration', async () => {
    const result = await showCurrentMode();
    expect(result.success).toBe(true);
    expect(result.message).toContain('当前模型配置');
    expect(result.message).toContain('提供商');
    expect(result.message).toContain('模型');
  });
  
  it('should handle missing config file gracefully', async () => {
    // Mock文件不存在场景
    mockFs.readFile.mockRejectedValue({ code: 'ENOENT' });
    const result = await showCurrentMode();
    expect(result.success).toBe(false);
    expect(result.message).toContain('配置文件不存在');
  });
  
  it('should include file modification time', async () => {
    const result = await showCurrentMode();
    expect(result.message).toContain('最后修改');
  });
});
```
