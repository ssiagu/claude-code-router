## Story

**作为** 应用用户  
**我需要** 在操作出错时获得清晰的错误信息和具体的解决建议

**CLI错误处理模式** (基于现有CLI命令):
- 成功: 输出到stdout，退出码0
- 错误: 输出到stderr，退出码1
- 保持与现有命令的一致性

**错误分类设计**:
```typescript
enum ErrorLevel {
  WARNING = 'warning',
  ERROR = 'error', 
  FATAL = 'fatal'
}

interface EnhancedError {
  code: string;
  level: ErrorLevel;
  title: string;
  description: string;
  suggestions: string[];
  examples: string[];
  helpCommands: string[];
}
```

**错误消息模板示例**:
```
❌ 错误: 模型不存在

问题描述:
  模型 'invalid,model' 在配置中不存在

具体原因:
  • 提供商 'invalid' 未在配置中找到
  • 可能的拼写错误或配置缺失

解决方法:
  1. 查看可用模型: ccr mode --list
  2. 检查提供商名称拼写
  3. 使用正确格式: ccr mode <提供商>,<模型>

示例命令:
  ccr mode deepseek,deepseek-chat
  ccr mode openrouter,gpt-4

获取帮助: ccr mode --help
```

**视觉增强策略**:
- ❌ 红色 - 错误/失败
- ⚠️ 黄色 - 警告  
- ✅ 绿色 - 成功
- 💡 蓝色 - 提示和建议
- 📝 - 示例和帮助

**复杂错误处理场景**:
1. **配置文件损坏**: 分步修复指导
2. **权限不足**: 权限检查和修复
3. **首次使用**: 完整设置引导
4. **网络连接**: 连接性检查建议

  it('should provide detailed error for invalid provider', async () => {
    const result = await executeModeCommand(['invalid,model']);
    expect(result.success).toBe(false);
    expect(result.message).toContain('❌ 错误');
    expect(result.message).toContain('提供商');
    expect(result.message).toContain('解决方法');
    expect(result.message).toContain('ccr mode --list');
  });
  
  it('should include helpful suggestions', async () => {
    const result = await executeModeCommand(['wrongformat']);
    expect(result.message).toContain('示例命令');
    expect(result.message).toContain('ccr mode');
  });
  
  it('should use visual enhancements', async () => {
    const result = await executeModeCommand(['invalid,model']);
    expect(result.message).toContain('❌');
    expect(result.message).toContain('💡');
  });
});
