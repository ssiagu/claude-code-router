# Story 1.3: 集成CLI命令系统

## Status
Ready for Review

## Story

**作为** 命令行用户  
**我需要** 在现有的 ccr 命令中使用 mode 功能  
**这样** 就能保持命令使用习惯的一致性，通过熟悉的CLI界面管理模型配置

## Acceptance Criteria

1. `ccr mode provider,model` 命令正常工作，成功切换默认模型
2. `ccr mode` (无参数) 命令显示当前模型配置信息
3. `ccr mode --show` 别名功能正常工作
4. `ccr mode --list` 显示所有可用模型列表
5. 命令参数正确传递给 modeCommand 模块处理
6. 帮助信息 (`ccr --help`) 包含 mode 命令说明
7. 错误处理与其他CLI命令保持一致的格式和风格
8. 所有现有命令功能不受影响，完全向后兼容

**CLI集成测试场景**:
```typescript
describe('CLI Mode Command Integration', () => {
  it('should execute ccr mode provider,model successfully', async () => {
    const result = await execCLI(['mode', 'deepseek,deepseek-chat']);
    expect(result.exitCode).toBe(0);
    expect(result.stdout).toContain('成功切换');
  });
  
  it('should show current mode with ccr mode', async () => {
    const result = await execCLI(['mode']);
    expect(result.exitCode).toBe(0);
    expect(result.stdout).toContain('当前默认模型');
  });
  
  it('should show help including mode command', async () => {
    const result = await execCLI(['--help']);
    expect(result.stdout).toContain('mode');
  });
});
```
